# WheelCollider Demo

Prefab-free runtime bootstrapper demonstrating `VehicleFollower`, `WheelColliderVehicleDrive`, `FollowTargetAnchor`, and `UnloadZoneTrigger`.

## How to Run
1. Import this sample from Unity Package Manager (**Window -> Package Manager -> Vehicle Follow -> Samples -> Import**).
2. Create an empty scene with a Directional Light and Main Camera.
3. Add an empty GameObject and attach `WheelColliderFollowDemoSetup`.
4. Ensure the `"Vehicle"` tag exists in **Project Settings -> Tags and Layers** (default Unity built-in or custom tag) and press **Play**.
